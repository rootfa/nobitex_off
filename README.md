# کد دعوت نوبیتکس چیست؟
منظور از کد دعوت، دقیقا همان کد تخفیف نوبیتکس است که در بالا برایتان قرار داده ایم. اگر ثبت‌نام خود را در نوبیتکس (Nobitex) با این کد دعوت تکمیل کنید، تخفیف 10 درصدی کارمزد معاملات به صورت خودکار روی اکانت شما اعمال می‌شود.
